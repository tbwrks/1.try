# Angebots-Briefing — das füllst du aus (mehr nicht)

Kopiere den Block, fülle die Werte, schick ihn an Claude. Alles, was du weglässt, wird mit dem Standard aus dem Baukasten (`02-baukasten.md`) gefüllt.

```
KUNDE:      [Name, Firma, Straße, PLZ Ort]
ANSPRACHE:  [Du / Sie] + [Vorname für Anrede, z. B. „Lieber Christoph"]
SEGMENT:    [GRÜNDER / BESTAND / PREMIUM]
ANLASS:     [1–2 Sätze: worum geht's, was ist das Ziel des Kunden]

MODULE:     [z. B. M1-M, M2-M, M3-S, M4-M]           ← Kürzel + Größe aus Baukasten
RETAINER:   [nein / M5-S 12 Monate / M8-S 6 Monate]
OPTIONEN:   [optionale Module, die als 2. Paket/Option gezeigt werden, z. B. M5-M, M7]

START:      [KW oder Datum]
ZAHLUNG:    [Standard / 50-50 / individuell: …]
NUTZUNG:    [Standard / Buyout inkl. (+ Aufpreis einrechnen)]
BESONDERES: [Freitext: Rabatt-Deal, Ausschlüsse, Versprechen aus dem Gespräch]
```

## Beispiel (hätte das Fetsch-Angebot erzeugt)

```
KUNDE:      Dominik Fetsch, Donaustraße 64, 86633 Neuburg
ANSPRACHE:  Du + „Lieber Dominik"
SEGMENT:    GRÜNDER
ANLASS:     Unternehmensgründung; braucht professionellen Auftritt und danach
            kontinuierlich Reichweite/Anfragen ohne eigenen Aufwand.

MODULE:     M1-S, M2-M, M3-S, M4-M
RETAINER:   nein
OPTIONEN:   Option 2 = zusätzlich M3-M statt M3-S + M5-S 12 Monate; M7 auf Anfrage

START:      Februar
ZAHLUNG:    Standard
NUTZUNG:    Standard
BESONDERES: —
```

Daraus entsteht automatisch: Modul 1 (Basispaket) ≈ 6.950 € netto, Option 2 = Basispaket + 350 €/Monat Kommunikations-Retainer — statt bisher 5.025 € mit versteckten 12-Monats-Gratisleistungen.

## Was Claude daraus macht

1. Bausteine + Preise aus `02-baukasten.md` ziehen (Segment-Faktor anwenden, auf 50 € runden).
2. Angebot nach `04-angebotsvorlage.md` aufbauen (Anschreiben wird aus ANLASS personalisiert).
3. Alle Summen quer rechnen (Netto → Brutto ×1,19), Daten prüfen, Standardkonditionen anhängen.
4. Fertigen Text liefern — du liest nur noch Korrektur und setzt ihn in dein Layout.
