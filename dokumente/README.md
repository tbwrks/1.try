# Ablage für Rohmaterial (tbwrks)

Hier kommen **deine** Originaldokumente rein — das einzige zulässige Rohmaterial
für das Betriebssystem. Nichts außerhalb dieses Ordners fließt in die Analyse ein.

## Was hier reingehört
Strategien · Markenentwicklungen · Positionierungen · Workshops · Präsentationen ·
Konzepte · Pitch-Unterlagen · Notizen · Kundenprojekte.

Formate: PDF, PPTX/Keynote-Export, DOCX, Markdown, TXT, Bilder von Slides.

## Empfohlene Benennung (hilft bei der Belegführung)
`JAHR_kunde_typ_titel.pdf`
Beispiele:
- `2023_tws_positionierung_moments-in-movement.pdf`
- `2022_pltalents_pitch_rebranding.pdf`
- `xxxx_intern_workshop_notizen.pdf`

Jahr/Kunde unbekannt → `xxxx` bzw. `intern`. Lieber grob taggen als weglassen.

## Ablauf pro Upload
1. Datei hier ablegen (einzeln ist völlig okay).
2. Ich lese sie vollständig, extrahiere Muster und trage sie ins
   `analyse/00_aufnahme-protokoll.md` ein — mit Belegstelle (Datei + Seite/Slide).
3. Erst wenn genug Material da ist, verdichte ich und baue das Blueprint.
