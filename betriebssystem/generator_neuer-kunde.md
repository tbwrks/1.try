# Generator: Neuer Kunde → Erstkonzept (tbwrks-Stil)

*So wird das Betriebssystem operativ. Fülle Teil 1 mit den Kundeninfos. Teil 2 zeigt,
wie daraus Schritt für Schritt ein Erstkonzept in Tobias' Denk- und Gestaltungslogik
entsteht. Teil 3 ist die Struktur des auszugebenden Decks. Alle Regeln aus
`00_tbwrks-blueprint.md`; Referenzfälle in `kontext/case-library.md`.*

## TEIL 2 — Ableitungs-Kette (so denkt das System)

**Schritt 0 — Projekttyp bestimmen** (Entscheidungsbaum Kap. 18):
→ A Consulting · B Rebranding · C Varianten · D Exploration · E Event · F Editorial.
Das legt fest, welche Phasen laufen und wie viele Richtungen gezeigt werden.

**Schritt 1 — Decodierung.** IST-Zustand + Produkt + Besonderheit in **3–4 Schlagworte**
übersetzen (= DNA). *Muster:* je Wert ein Schlagwort + eine Symbolik.
`DNA = [Wort1] · [Wort2] · [Wort3]`

**Schritt 2 — Golden Why.**
`WARUM: [Sinn/Haltung dahinter]  ·  WIE: [auf welche Art]  ·  WAS: [konkrete Leistung]`

**Schritt 3 — Verdichtung zum Kern.** 3–5 Kern-Sätze anbieten, einen empfehlen.
`KERN (empfohlen): „[ein Satz, der alles trägt]"`

**Schritt 4 — Positionierung per Gegenüberstellung.**
`„Wollen wir [das Naheliegende/Gewohnte]? — Wir wollen [das Richtige]!"`
`SCHÄRFUNG: „[Positionierung in einem Satz]"`

**Schritt 5 — Metapher wählen** (Brücke von Wert zu Bild).
`METAPHER: [Tier/Naturbild/Symbol] — weil es [Wert] repräsentiert.`

**Schritt 6 — Name/Claim** (falls nötig): 3 Optionen mit Für/Wider + Empfehlung.
Claim gern mit Wortspiel/Hashtag. `CLAIM: „[…]"  #[hashtag]`

**Schritt 7 — Richtungen (Basis aus X).** Je nach Budget 1 / 2 / 3–4 **kontrastierende**
Richtungen aus verschiedenen Ankern (Person / Zielgebiet / Leistung / Gefühl / Tradition …).
Jede Richtung durch **dasselbe Raster**: `Zeichen · Farbe · Schrift · Bild · Form`.

**Schritt 8 — Wirkung → Codierung je Element.**
`FARBE — Wirkung: [was es auslösen soll] → Codierung: [Primär/Kontrast/Sekundär…]`
(analog für Schrift, Form, Bild, Zeichen).

**Schritt 9 — Touchpoints kanalisieren.** Vollständige Liste statt Beispiele; passend zur
Branche (Offline / Bewegtbild / Social / Web / Event / Print / Merch).

**Schritt 10 — Fortentwicklung & Wert-Rahmung.** Ausbau (Plakat/Web/Merch/Hashtags) andeuten;
bei Budget-Skepsis „Warum das Ganze?" ergänzen.

## TEIL 3 — Auszugebendes Deck (Struktur)

> Kapitelnamen an Projekttyp anpassen (Kap. 3). Meta-Design: Flieder-Akzent, große kursive
> Statement-Headlines, zweiteilige Überschriften (2. Wort in Akzentfarbe), viel Weißraum.

1. **Cover** — „Creative Direction | [Kunde]" + Kapitelübersicht
2. **Grundformel** — „Klares Ziel + Tiefes Verständnis = Strategische Gestaltung"
3. **01 Analyse/Strategie** — Decodierung (progressiv) → DNA → Golden Why → Big Picture
4. **Positionierung** — Gegenüberstellung + Schärfung
5. **Kern** — Verdichtung + Metapher + (Name/Claim)
6. **02 Visualität** — Richtungen (kontrastierend, gleiches Raster); je Element Wirkung→Codierung
7. **Kontrast-Folie** — Optionen nebeneinander, Empfehlung hervorgehoben
8. **03 Anwendung** — kanalisierte Touchpoints
9. **Fortentwicklung** — Ausbau + ggf. „Warum das Ganze?"
10. **Schlussakkord** — ein zitierfähiger Leitsatz
11. **Dankeschön** — Datum + Urheberrechts-Footer (Zwischenstand = „Projekt Statusgeber")
