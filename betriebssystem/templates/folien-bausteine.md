# Folien-Bausteine (wiederverwendbar)

Belegte, wortnahe Vorlagen aus den Projekten. `[…]` = Platzhalter.

---

## Cover
```
Creative Direction        (bzw. „Creative Consulting")
[Kundenname / Projekttitel]

01_[Kapitel]
02_[Kapitel]
03_[Kapitel]
```
Footer (Urheberrechts-Block, 8/10 belegt, wortgleich):
> Die Inhalte dieser Präsentation unterliegen meinem Urheberrecht (tbwrks). Jegliche
> Verwendung, Vervielfältigung, Verbreitung oder Weitergabe der in dieser Präsentation
> enthaltenen Informationen ist ohne meine ausdrückliche schriftliche Genehmigung untersagt.
> Diese Einschränkung gilt bis zur vollständigen Bezahlung der vereinbarten Vergütung für die
> Nutzung der Inhalte.


## Golden Why
```
WARUM   Warum gibt es das?      [Sinn/Haltung]
WIE     Wie erreicht es das?    [Art & Weise]
WAS     Was machen wir dafür?   [Leistungen: • … • … • …]
```

## Wirkung → Codierung (je Gestaltungselement)
```
[Farbe | Schrift | Form | Bild | Zeichen]

```

## Richtung / „Basis aus X"
```
Visualität aus [Klarheit | Emotion | Tradition | Person | Zielgebiet | Leistung]
Decodierung der Basis: [W1] · [W2] · [W3] · [W4]
Raster: Zeichen · Farbe · Schrift · Bild · Form
Anwendung: Anmutung · Bühne · Media · Offline · Event · Partner
```

## Gegenüberstellung (Positionierung)
```
„Wollen wir [das Gewohnte, Naheliegende]?"
„Wir wollen [das Richtige, Anspruchsvolle]!"
```

## Wert-Rahmung / „Warum das Ganze?"
```
Es geht nicht darum, maximale Veränderung mit minimalem Aufwand.
Es geht um echte Begehrlichkeit mit maximalem Effekt.
KPI: keep people interested · informed · involved · integrated · inspired
```

## Schlussakkord
```
„Es muss nicht immer viel sein, nur gut ist schon nicht leicht."   (oder projektspezifisch)
```
